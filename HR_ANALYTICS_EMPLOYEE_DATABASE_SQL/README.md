# HR ANALYTICS & EMPLOYEE DATABASE

A professional MySQL portfolio project for analyzing employees, departments, salaries, attendance, leave, performance, skills and projects.

## SQL Skills
DDL, DML, constraints, JOINs, aggregations, subqueries, CTEs, CASE, window functions, views, stored procedures, triggers and indexes.

## Run Order
1. create_database.sql
2. create_tables.sql
3. insert_sample_data.sql
4. Run analysis files in queries
5. Run views, procedures, triggers and indexes as required.

## Main Analysis
Employee salary analysis, department performance, attendance, leave usage, employee ranking, salary bands, skills, project assignments and HR KPIs.
